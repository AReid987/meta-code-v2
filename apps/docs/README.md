# AREID Protocol Documentation (`apps/docs`)

The centralized knowledge hub for the Autonomous Resilient Economic Intelligence Dispatcher. This site hosts technical guides, API references, and architectural specifications for the AREID ecosystem.

## 🚀 Key Content

- **Getting Started:** Step-by-step guides for setting up your first refinery.
- **API Reference:** Comprehensive documentation for the Hub's OpenAI-compliant endpoints.
- **Economic Theory:** Deep dives into the "Guerilla Reasoning Economy" and "Battery" model.
- **Developer Guides:** Instructions for adding new providers, identity clusters, and custom hacks.

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+
- pnpm 10+

### Run Development Server
```bash
pnpm dev
```
Open [http://localhost:3001](http://localhost:3001) to view the documentation.

## 🏗️ Architecture

- **Framework:** Next.js 16 (App Router)
- **Content:** Markdown-driven documentation.
