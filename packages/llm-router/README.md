# AREID TypeScript Router (`packages/llm-router`)

Shared TypeScript utilities and schemas for the AREID ecosystem. This package provides a unified interface for interacting with the Hub API from Next.js and other Node.js-based tools.

## 🚀 Key Features

- **Hub Client:** Type-safe fetcher for communicating with the AREID Proxy Hub.
- **Shared Schemas:** Zod definitions for `ChatCompletionRequest` and `ChatCompletionResponse`.
- **Metadata Parsers:** Utilities for extracting `_reid_metadata` from response payloads.

## 🏗️ Technical Stack

- **Language:** TypeScript
- **Validation:** Zod
- **Build:** Turborepo-integrated
