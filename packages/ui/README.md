# AREID UI Component Library (`packages/ui`)

Shared React component library for the AREID ecosystem. This package provides the atomic and molecular UI elements used in the Web Dashboard and Documentation site.

## 🚀 Key Components

- **Dashboard Cards:** High-tech stats and status displays.
- **Quota Grids:** Visual representations of provider health.
- **Log Viewers:** Styled inference path and stream displays.
- **Theme Engine:** Centralized Tailscale-compatible dark theme configuration.

## 🏗️ Technical Stack

- **Language:** TypeScript
- **Framework:** React 19
- **Styling:** TailwindCSS v4
